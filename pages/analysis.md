# Разбор описания

## Существительные

| Из описания | Класс | Назначение |
| --- | --- | --- |
| Поликлиника | Clinic | Место работы сотрудников и проведения приемов |
| Врач | Doctor | Принимает пациентов, ставит диагнозы, выписывает рецепты |
| Пациент | Patient | Человек, который обращается в поликлинику |
| Прием | Appointment | Событие, связывающее врача, пациента и поликлинику |
| Диагноз | Diagnosis | Результат осмотра, содержит название болезни |
| Рецепт | Prescription | Назначение лекарства и способ его применения |
| Лекарство | Medicine | Сведения о лекарстве |
| История болезней | MedicalHistory | Приемы и их результаты для одного пациента |
| Медсестра | Nurse | Помогает врачу и выполняет процедуры |
| Процедура | Procedure | Запись о выполненной процедуре |

«Болезнь» представлена полем diseaseName в Diagnosis. Отдельный справочник болезней для этого задания не нужен

Название системы относится ко всей модели. Отдельный класс с названием «Больничная информационная система» не добавляется

## Поля

У поликлиники есть название и адрес. У врача и медсестры — ФИО, у врача также специальность. У пациента — ФИО и дата рождения

Прием хранит дату и время. У диагноза есть название болезни и описание. Рецепт хранит дозировку и указания по применению. Лекарство содержит название и форму выпуска

История болезней имеет номер. Процедура содержит название, описание и дату выполнения

Эти поля уточняют объекты модели. Точный набор личных данных и формат хранения дат в задании не определены

## Действия

| Из описания | Где отражается |
| --- | --- |
| Врач принимает пациента | Doctor.receive(appointment) |
| Врач ставит диагноз | Doctor.makeDiagnosis(appointment, diseaseName, description) |
| Врач выписывает рецепт | Doctor.writePrescription(appointment, medicine, dosage, instructions) |
| Пациент хранит историю болезней | Связь Patient с MedicalHistory, метод Patient.getMedicalHistory() |
| История хранит приемы | MedicalHistory.addAppointment(appointment), getAppointments() |
| Медсестра помогает врачу | Nurse.assist(doctor) |
| Медсестра выполняет процедуры | Nurse.performProcedure(appointment, name, description) |

Хранение истории показано связью, поскольку это состояние пациента. Доступ к ней оформлен методом. Чтобы связать действия, у поликлиники добавляется createAppointment(), а у приема — методы добавления диагноза, рецепта и процедуры

Сначала создается прием. Его передают врачу и медсестре, чтобы результаты относились к определенному обращению пациента
